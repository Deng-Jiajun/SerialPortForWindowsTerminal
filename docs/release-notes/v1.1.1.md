# v1.1.1

更新于 2026-11-05，以下为相对 `v1.1.0` 的补丁修复。

- 恢复本地编辑模式的 `Ctrl+C` 中断发送，按下后取消草稿并立即发送单字节 `0x03`
- 为 `Ctrl+C` 增加青色 `> ^C` 发送记录，时间戳跟随设置，并过滤发送后 1 秒内首条完整匹配的设备回显
- 修复单独按 `Esc` 后吞掉下一次输入的问题，控制键立即处理，普通字符以 100 ms 区分 Alt 组合输入
- 修复 SS3 编码的方向键、Home 和 End 被拆开解析、误插入字符的问题
- 修复粘贴内容以不完整转义序列结尾时影响粘贴结束识别的问题，结束粘贴后回车、`Ctrl+C` 和 `Ctrl+K` 可正常使用

回显过滤规则见[输入、历史与日志](../terminal.md#时间戳与命令回显)。
