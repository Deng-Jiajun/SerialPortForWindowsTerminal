# v1.1.0

发布日期：2026-10-28。以下为相对 v1.0.0 的变化。

## 终端操作

- 新增本地命令历史和灰色建议，支持按前缀翻阅、中文编辑及草稿恢复；输入行固定在底部，日志在上方持续滚动
- 新增接收 / 发送时间戳，默认开启，可在设置中关闭
- 新增 `Ctrl+K`「终端设置」窗口，可在连接期间切换 UTF-8 / GBK、输入模式和时间戳，也可退出终端；打开弹窗期间继续接收日志
- 本地编辑回车只发送一个 `CR`，避免设备 shell 把 `CRLF` 当成两次提交；空回车保留发送记录
- 保留本地命令的青色发送记录，隐藏发送后 1 秒内首条完全匹配的设备回显，减少重复显示

## 断开与关闭

- 串口接收失败时显示错误码、原因和重新打开的提示，并以非零退出码结束；Windows Terminal 的 `closeOnExit: automatic` 可保留错误页
- 关闭标签页时取消输入输出并等待线程退出，清理等待最多 3 秒
- 在串口设置弹窗结束后重新注册关闭回调，修正输入法组件卸载后旧回调仍可能被调用的问题

## 使用与升级

- 原 `Ctrl+A` 前缀组合键改为 `Ctrl+K` 设置窗口；本地编辑中的 `Ctrl+C`、`Ctrl+D` 不发送到设备，需要中断或 EOF 时切换到字符透传
- 回显过滤只用于本地命令显示；设备未开启回显时，首条同名实际输出也可能被隐藏
- 继续使用原注册表配置；命令历史保存在 `%LOCALAPPDATA%\SerialForWindowsTerminal\history.txt`
- 更新前退出串口终端，用新包替换原目录中的两个 EXE；Windows Terminal 配置的程序路径无需改变
- 删除源码仓库中的旧 `ReleaseBin`，可执行文件统一从 Releases 下载；使用说明、外部控制和开发说明随 ZIP 一起提供

附件提供 x64、x86 两个 ZIP 及 `SHA256SUMS.txt`。64 位 Windows 通常选择 x64。
